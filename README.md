# ETF基金监控系统

这是一个基于Streamlit的ETF基金监控网页应用，用于实时监控多只ETF基金的关键指标。

## 功能特点

- 📊 实时获取ETF基金历史行情数据
- 📈 计算20日涨幅百分比
- 📉 计算28日移动平均线
- ⚠️ 判断是否跌破28日均线
- 🎨 极简风格的现代化界面
- 🔄 一键刷新数据

## 监控的ETF基金

- **159941** - 纳指ETF
- **513050** - 中概互联网ETF  
- **511090** - 30年国债ETF
- **510300** - 300ETF
- **519915** - 创业板ETF

## 安装和运行

1. 安装依赖包：
```bash
pip install -r requirements.txt
```

2. 运行应用：
```bash
streamlit run app.py
```

3. 在浏览器中打开显示的URL（通常是 http://localhost:8501）

## 数据来源

使用akshare库获取新浪财经的基金行情数据，数据更新及时且准确。

## 技术栈

- **Streamlit** - Web应用框架
- **akshare** - 金融数据接口
- **pandas** - 数据处理
- **numpy** - 数值计算
